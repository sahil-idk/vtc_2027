# TWINGATE Architecture Diagram

Excalidraw source (editable):
https://excalidraw.com/#json=H6ZnbYxat8HKbDoGu7C1C,6cXD_m5b0ezmy57OSNVoZw

To use in LaTeX:
1. Open the link above
2. File > Export image > PNG (or PDF for vector)
3. Save as `twingate_architecture.pdf` in this folder
4. In main.tex, replace the TikZ figure block with:
   \includegraphics[width=\columnwidth]{Figures/twingate_architecture.pdf}

The TikZ version is already in main.tex as a fallback (compiles without any external file).
